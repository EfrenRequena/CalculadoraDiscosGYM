# CalculadoraDiscosGYM
Esta aplicación web es una herramienta educativa y práctica diseñada para calcular la mezcla exacta de materiales necesaria para fabricar discos de pesas de concreto de cualquier peso personalizado. El usuario ingresa el peso deseado del disco (en kg) y la aplicación devuelve la receta precisa de arena, cemento, piedras y agua.
