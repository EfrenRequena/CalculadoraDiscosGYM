# CalculadoraDiscosGYM
🏋️ Calculadora de Discos de Concreto
📝 Descripción del Proyecto
Esta aplicación web es una herramienta educativa y práctica diseñada para calcular la mezcla exacta de materiales necesaria para fabricar discos de pesas de concreto de cualquier peso personalizado.
El usuario ingresa el peso deseado del disco (en kg) y la aplicación devuelve la receta precisa de arena, cemento, piedras y agua, además del Módulo de Finura de la mezcla.
Características principales:
🎨 Estética Retro: Diseño inspirado en monitores CRT antiguos, con efectos de scanlines, aberración cromática y animaciones "glitch".
📱 100% Responsive: Se adapta perfectamente a dispositivos móviles, tablets y computadoras de escritorio.
⚡ Arquitectura SPA (Single Page Application): Navegación instantánea entre vistas sin recargar la página, construida con JavaScript Orientado a Objetos (POO).
🤖 Validaciones con Personalidad: El personaje "Pixelman" ofrece mensajes de error humorísticos y sarcásticos si se ingresan datos inválidos (letras, pesos negativos, cero o exagerados).
🔌 Sin dependencias: Funciona completamente en el lado del cliente (HTML, CSS, JS), sin necesidad de servidores ni bases de datos.
